## הרצה מקומית (Local Run)
```bash
npm install

```
כל השינויים נשמרים אוטומטית ב-`localStorage` של הדפדפן, וניתן לייצא ולייבא את התוכנית כקובץ `.json` בכל עת דרך תפריט הפרופיל בפינה הימנית העליונה.
